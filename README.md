
# 🌱 Upcycle Project Tracker

**Create less waste. Make more wonder.**

Upcycle Project Tracker is a Flutter mobile application prototype designed to encourage sustainable living through creative upcycling activities. It provides a platform for users to discover project ideas, follow tutorials, create their own projects and track their progress.

The application aims to promote responsible consumption and production in support of **United Nations Sustainable Development Goal 12 (SDG 12)**.

## ✨ Features

- **Onboarding:** Introduces users to the application's purpose and features.
- **User Authentication:** Login and registration interfaces with input validation.
- **Home Dashboard:** Displays project summaries, progress and featured projects.
- **Community Gallery:** Explore upcycling ideas with search and category filters.
- **Project Tutorials:** View project descriptions, materials, tools and step-by-step instructions.
- **Create & Edit Projects:** Add or modify project information.
- **My Projects:** Organise projects by their progress status:
  - Not Started
  - In Progress
  - Completed
- **User Profile:** View profile information, project activity and account settings.
- **Account Management:** View, edit and delete demo account information.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Android Studio or an Android emulator

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/RiskyFerdiansyah/upcycle-project-tracker.git
```

**2. Navigate to the project directory**

```bash
cd upcycle-project-tracker
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

## 📌 Project Scope

This project is developed as a front-end mobile application prototype using Flutter and Dart.

The current prototype uses predefined sample data to demonstrate its interface, navigation and interactions. Database and backend integration are not included in the current implementation.

## 🌍 Sustainable Development Goal

This project supports **SDG 12 – Responsible Consumption and Production** by encouraging users to reuse everyday materials, explore creative alternatives and reduce unnecessary waste through upcycling activities.
